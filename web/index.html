What runs here

The page loads one WebAssembly module containing the upstream Standard port, the puzzle/solution codecs and omsim's byte verifier. The browser calls the solver directly; no server or native worker is involved.

GitHub Pages serves these static files. It cannot provide custom COOP/COEP headers, so this first target is deliberately single-threaded. A verified solution is downloaded only after the in-process omsim check passes.
